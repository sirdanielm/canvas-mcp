# Goals, methods and current work

The aim is dependable grading support that saves teacher time while preserving
original evidence, exact identity, academic policy and teacher control. This page
owns the current agenda. Procedures belong in the linked guides; detailed case
history, approvals, installed pins and readback receipts remain private.

## Priorities

The current order is Unit 2 grading and feedback into canonical local EDIT,
then the remaining accepted Unit 1 packets, then formative participation.
Use retained evidence and existing domain engines; resolve actual source/policy
holds and preserve supported partial feedback when a numeric total remains
unknown. Complete each stage from its durable receipt rather than restarting
an entire packet.

Grading, paid calls, deployment and live Canvas publication are paused during
repository closeout. An overnight work order is a draft, not authority to resume.
Future execution needs current scoped authority and valid source capabilities;
an expired capability, saved plan or passing source test supplies neither.

For the Unit 2 handback, batch work by stage: admit exact source packets,
retain literal readings, apply the issued form and sealed policy, then check
score and full-feedback proposals. Resume each batch at its first unfinished
stage and reuse valid saved work. Keep review familiar and inspectable in the
existing Sheet/workbench while reusing the installed local engines. Qualifying
an optional front end is separate work. Consider a backend change only when an
observed workflow need warrants it. Teacher acceptance and delivery remain
separate gates.

1. Reuse valid saved evidence and results to produce useful proposals without
   repeating paid analysis or reconstructing work from chat history.
2. Preserve two intake lanes: Canvas submissions and teacher-folder/paper

## Grading flow

Both intake lanes retain their original bytes and provenance. Reuse an existing
result only when its source, policy, identity and substantive revision still
match. A paper reassessment label never supplies a Canvas attempt number.

| Work | Review and staging method | Final delivery |
| --- | --- | --- |
| Summative tests | Canvas or paper/folder intake → literal key-free reading → policy-bound scoring → clean itemized feedback → local review and central EDIT through its qualified route | Separately authorized score/full-feedback publication, each with its own transport history and readback |
| Formative participation | Canvas or paper/folder intake → source-bound participation proposal and private analysis → local QC/review → UNAPPROVED central EDIT draft | Fresh Canvas comparison, exact teacher approval and separately authorized **score-only** publication |

An ordinary draft may be staged before final teacher approval. It remains
UNAPPROVED and supplies no Canvas publication authority. Participation analysis
and local provenance notes are private; they are not student comments. Accepted
test scores and full feedback derive from the same reviewed result and retain
separate delivery evidence. Feedback-only drafts may preserve supported readable
work while a whole numeric total remains held. Missing source or identity is a
hold, never a zero.

The maintained accepted-result transfer requires an authenticated teacher
decision before EDIT staging. Unit 2 advisory and feedback-only drafts use
separately qualified private adapters; staging supplies no teacher acceptance.

Human feedback versions describe the saved body: v1 is the original, v2 removes
internal wrappers and shows deductions and unreadable holds, and v3 adds only the
shortest useful accurate FRQ key cue (at most 20 characters). Preserve the full
private key, original feedback and scoring evidence. At the October 20 pause,
cleaned v2 notes had bounded local EDIT readback; the v3 formatter candidate was
partly qualified and uninstalled, with no saved v3 notes. Internal schema names,
version labels and a formatter test do not establish the saved body or delivery.

notes and unresolved operations. A current absent comment does not prove a
historical append was never sent; reconcile its original history.

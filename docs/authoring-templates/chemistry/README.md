# Chemistry assignment body and rubric template

Copy the [HTML template](assignment-body.template.html) into the draft package.
Use the [Canvas authoring workflow](../../sdm-canvas-authoring-workflow.md)
to select the target and the applicable authoring profile.

1. Start with the approved worksheet and rubric for the exact Core or Advanced
   assignment. Fill each placeholder with the approved learning intention,
   scope, supports, directions, and resource links. Escape text and URL values.
2. Use the actual submission route in both the highlighted banner and the
   closing directions. Include new-window instructions for an External Tool
   only when the assignment uses that launch. Omit inapplicable resource links.
3. Fill the three rubric columns with item labels, expected evidence, and points.
   Use a row header for each criterion. Check that the sum of criterion points
   matches the assignment's `points_possible`.
4. Review the draft preview for readable headings, working student resource links,
   accurate Core or Advanced scope, and a complete rubric. Verify student access
   to each resource under the approved sharing policy. Keep teacher materials
   and source provenance in their existing private locations.

The template supplies the body layout and embedded rubric. The assignment
package supplies the scoring policy, submission route, and resource versions.
